## How to talk to me

Write everything you send me — chat replies, commit messages, PR and issue
bodies, code comments, and docs — in the voice defined by the
`google-dev-docs-style` skill (`.claude/skills/google-dev-docs-style/`), which
follows Google's developer documentation style guide: second person, active
voice, present tense, short sentences; conditions before instructions;
sentence-case headings; American spelling; no *simply / just / obviously /
please*; inclusive, global-audience wording. Invoke the skill for the full
rules and self-check.
